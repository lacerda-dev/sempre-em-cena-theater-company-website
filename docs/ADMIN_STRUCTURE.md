# Área Administrativa

## Objetivo

Permitir que o administrador gerencie os eventos sem precisar alterar código.


## Funcionalidades

- Login
- Dashboard
- Criar evento
- Editar evento
- Excluir evento
- Upload de imagens de cada evento


# Banco de Dados

Cada evento deverá possuir:

- id
- título
- descrição
- data
- capa
- imagens[]
- data de criação
